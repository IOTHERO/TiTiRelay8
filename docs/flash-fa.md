# راهنمای بارگذاری Firmware روی TiTi Relay-8

این پوشه همه‌چیزِ لازم برای پروگرام کردن برد را دارد و به Arduino IDE نیازی نیست.

| فایل | کاربرد |
|---|---|
| `TiTiRelay8-<نسخه>-full.bin` | همه‌چیز برای برد خام، از آدرس `0x0`: بوت‌لودر، پارتیشن‌ها، Firmware و رابط وب |
| `TiTiRelay8-<نسخه>-littlefs.bin` | فقط رابط وب، برای آپدیت از منو (صفحهٔ سیستم، گزینهٔ «فایل رابط کاربری») |
| `TiTiRelay8-<نسخه>-ota.bin` | فقط Firmware، برای آپدیت از منو (صفحهٔ سیستم) یا از پنل سازنده |
| `flash.bat` | پاک کردن کامل حافظه و نوشتن `full.bin` |
| `esptool.exe` | ابزار پروگرام ESP32 |
| `product-template.json` | تعریف محصول برای پنل سازنده |
| `SHA256SUMS.txt` | اثرانگشت فایل‌ها، برای اطمینان از سالم بودن آن‌ها |

## مراحل

1. برد را با کابل USB به کامپیوتر وصل کنید. شمارهٔ پورت را در Device Manager ببینید
   (مثلاً `COM5`).
2. پنجرهٔ Command Prompt را در همین پوشه باز کنید و بزنید:
   ```
   flash.bat COM5
   ```
3. اگر اتصال برقرار نشد، دکمهٔ **BOOT** برد را هنگام «Connecting…» نگه دارید.
4. پس از پایان، برد خودش ریست می‌شود. در مانیتور سریال (`115200`) پیام شروع با نسخه و MAC
   دیده می‌شود.

## پس از بارگذاری

- **خط تولید:** شناسه و رمز هر برد را با `hub-provision` از فایل CSV پنل سازنده بنویسید.
- **نصب در محل:** دیپ‌سوئیچ ۸ را روشن کنید، برد را روشن کنید و به وای‌فای `TiTi-R8-xxxx`
  (رمز `titi1234`) وصل شوید. سپس نشانی `192.168.1.100` را باز کنید. ادامهٔ کار مطابق پوستر راهنما است.
- `flash.bat` کل حافظه را پاک می‌کند، شناسهٔ دستگاه هم پاک می‌شود. برای آپدیت بردی که
  در حال کار است، فقط فایل `ota.bin` را از منو یا پنل سازنده نصب کنید.
